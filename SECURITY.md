# Security Policy

## Supported version

The `main` branch is the maintained portfolio version.

## Reporting

Do not open public issues containing secrets, credentials, personal data or exploitable security details. Report sensitive findings privately to the repository owner.

## Security boundaries

- Never commit API keys or credentials.
- Provider keys belong in server-side environment variables.
- Generated tests are not automatically approved.
- Sensitive MCP actions require explicit human approval and an approver identity.
- This repository is a demonstration and learning system, not a production release authority.

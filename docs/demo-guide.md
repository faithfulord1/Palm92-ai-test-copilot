# Demo Guide

1. Start with `npm start`.
2. Open `http://localhost:3000`.
3. Analyse a login + MFA requirement.
4. Generate test drafts and point out that every AI-generated test remains `Pending`.
5. Demonstrate the ANTON / Antonio phone-number case: `(5) 555-3932` vs `555-3932` is semantically equivalent but not an exact-format match.
6. Show an evidence record with correlation ID, before state, action, expected/actual, after state, verification and approval.
7. Demonstrate a sensitive MCP action failing without approval, then succeeding only after explicit human approval.

Closing line: **AI accelerates testing. Humans control quality decisions.**
